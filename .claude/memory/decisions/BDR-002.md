# BDR-002 — Utiliser html-to-image pour l'export PNG côté client

| Décision                                      | Pourquoi                                                                           | Alternatives considérées                             | Statut |
| --------------------------------------------- | ---------------------------------------------------------------------------------- | ---------------------------------------------------- | ------ |
| Utiliser `html-to-image` pour exporter en PNG | Fonctionne entièrement côté client, pas de serveur requis, supporte les styles CSS | Canvas API native, Puppeteer (serveur), dom-to-image | actif  |
