# BDR-005 — Layout responsive `flex-col-reverse md:flex-row` pour Icon Maker

| Décision                                                         | Pourquoi                                                                                                                    | Alternatives considérées                                    | Statut |
| ---------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- | ------ |
| Utiliser `flex-col-reverse` sur mobile et `flex-row` sur desktop | Controls first dans le DOM (sidebar gauche naturelle en desktop) + visuellement en bas sur mobile sans modifier l'ordre DOM | `order-` utilities, réécriture de l'ordre DOM, bottom sheet | actif  |

Controls est premier dans le DOM → en `flex-row` desktop il apparaît à gauche ✓. En `flex-col-reverse` mobile il apparaît visuellement en bas, canvas en haut ✓. Aucune duplication de JSX ni de logique d'ordre.
