# LRN-003 — `w-full aspect-square` pour canvas html-to-image responsive

## Pattern

Remplacer les dimensions hardcodées (`width: 400, height: 400`) par `className="w-full aspect-square"` sur le div capturé. L'export reste fidèle car `toPng` utilise `pixelRatio = EXPORT_SIZE / element.offsetWidth` — `offsetWidth` reflète la taille réellement rendue, quelle qu'elle soit.

## Pourquoi ça marche

html-to-image capture le DOM tel qu'il est rendu. Si le canvas est 320px sur mobile, `pixelRatio = 1080 / 320 = 3.375` → PNG 1080×1080 identique. Aucune logique JS supplémentaire.
