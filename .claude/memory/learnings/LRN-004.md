# LRN-004 — `flex-col-reverse` pour inverser l'ordre visuel mobile sans modifier le DOM

## Pattern

Quand un composant doit être **premier dans le DOM** (pour la sémantique ou l'ordre desktop) mais **visuellement en bas sur mobile** :

```css
/* Mobile : flex-col-reverse → premier enfant DOM = bas de page */
/* Desktop : md:flex-row → premier enfant DOM = gauche */
.container {
  display: flex;
  flex-direction: column-reverse;
}
@media (min-width: 768px) {
  .container {
    flex-direction: row;
  }
}
```

En Tailwind : `flex flex-col-reverse md:flex-row`.

## Cas d'usage ici

Sidebar Controls doit être à gauche en desktop (premier dans le DOM = naturel en `flex-row`) et en bas sur mobile (après le canvas). `flex-col-reverse` évite de dupliquer le JSX ou d'utiliser des `order-` utilities complexes.
