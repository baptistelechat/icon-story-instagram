## Friction

Build Vercel échoué avec :

```
src/components/Controls/components/ColorInput.tsx(16,18): error TS2554: Expected 1 arguments, but got 0.
ELIFECYCLE  Command failed with exit code 2.
```

## Cause

`useRef<number>()` sans argument dans `ColorInput.tsx:16` — surcharge supprimée en React 19.

## Résolution

```ts
// Avant
const rafRef = useRef<number>();

// Après
const rafRef = useRef<number | undefined>(undefined);
```

Build local validé (`pnpm build` → ✅), React Doctor post-fix → 99/100.
