# BLK-004 — Color picker laggy : deux tentatives pour identifier la vraie cause

## Symptôme

Dragging sur `<input type="color">` → lag perceptible sur l'ensemble de l'app, couleur difficile à ajuster précisément.

## Tentative 1 — insuffisante

Suppression du prop `iconColor` d'`IconPicker` pour éviter le re-render des 80 icônes. Lag persistant.

## Cause réelle

`onChange` du color picker fire à chaque pixel de mouvement souris → `setState` synchrone dans `App` → re-render complet de tout l'arbre → main thread bloqué → lag du picker natif lui-même.

## Résolution

État local `localValue` dans `ColorInput` + `requestAnimationFrame` comme debounce :

```tsx
const rafRef = useRef<number>();
const handleColorPicker = (e) => {
  setLocalValue(e.target.value);
  if (rafRef.current !== undefined) cancelAnimationFrame(rafRef.current);
  rafRef.current = requestAnimationFrame(() => onChange(e.target.value));
};
```

Max 1 propagation vers `App` par frame (~16ms). Le picker natif reste fluide car le main thread n'est plus saturé.

## Statut

Résolu — voir aussi GLRN-008 (pattern global RAF debounce).
